py_observable_order_from_data

描述

Python 可调用（数组版，供样例/分享用）： py_observable_order_from_data(trade_arrays, market_arrays, params=None, with_curvature=True)

  • trade_arrays：形状 (n, 7) 的 float64 数组，列序 [exchtime_us, price, volume, turnover, flag, bid_order, ask_order] （exchtime_us = 原始 Level2 transaction.csv 的 exchtime 列；flag==32 的撤单在这里丢掉）
  • market_arrays：形状 (m, 46) 的 float64 数组，列序 [exchtime_us, last_prc, volume, turnover, total_ask_vol, total_bid_vol, ask_prc1..ask_prc10, ask_vol1..ask_vol10, bid_prc1..bid_prc10, bid_vol1..bid_vol10]
  • params：同 py_compute_observable_order_metrics 的参数字典；with_curvature=False 输出 19 统计量口径（50400 列），True 输出 21 统计量口径（52416 列）

与 pipeline=observable_order 的逐股输出逐位一致。

函数签名

py_observable_order_from_data(trade_arrays, market_arrays, params, with_curvature) -> None

此函数没有参数
