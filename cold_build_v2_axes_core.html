cold_build_v2_axes_core

描述

Cold v2 三正交冷门轴构造内核： 输入带前导历史窗口（共 d_full = out_offset + d_out 行）且已完成 lag 平移的行情矩阵， 以及目标区间 (d_out, s, 10) 的 barra_ranked（rank_pct）和 (d_out, s) 的 restrict（0=正常）。 返回 (d_out, s, 3) f32：[C1_PriceCold, C2_TurnCold, C3_LotteryCold]，严格正交于 [1, rank_pct(Barra10)]。

函数签名

cold_build_v2_axes_core(close, turn, high, low, raw_close, high_limit, barra_ranked, restrict, out_offset) -> None

参数

此函数没有参数
