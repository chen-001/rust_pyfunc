一、你的核心指标是什么

把 A 全天每一笔和 B 全天每一笔两两配对，时间差按指数衰减加权求和。名字叫距离，实际上是互动强度，成交越多越大，所以必须用自能量归一化之后才可比。

原算子（10ms 桶实现，行在后列在前，同桶 50/50 折半） S(A, B) = Σa ∈ A Σb ∈ B wa · wb · e−|ta − tb| / τ EA = 2 · Sdir[A][A] ρ(A, B) = S(A, B) √(EA · EB) |ρ| ≤ 1

你帖子里的 37 张矩阵就是这个式子换 6 种权重和多个 τ。正式口径在 src/yupei_dist/matrix_stage.rs 第 3 行起。

关键事实
拼接满足严格的 S(A, UBC) = S(A, B) + S(A, C)， 我用独立 Python 暴力复算过，相对差 0.0（有向核 1.4 × 10−16）。 这条意味着拼接本身不产生任何新信息，全部信息都藏在归一化的分母里。

二、你这个思路哪里站得住、哪里要改

站得住的地方

换成归一化之后，互补和重复确实分得开了。而且互补图跟相似图在图结构上几乎不重合，k=20 时平均共同邻居只有 0.55%，两个度序列的 Spearman 是 −0.384。这不是相似度换了个说法。

问题一 · 硬天花板

ρ(X, UBC) = wB·ρ(X,B) + wC·ρ(X,C) ≤ √(p² + q²) ≤ √2 · max(p, q) 其中 wB = √eB / D，wC = √eC / D， D = √(eB + eC + 2·ρ(B,C)·√(eB·eC))， p = ρ(X,B)，q = ρ(X,C)

所以「A 离拼接后很近、但离 B 和 C 都远」在数学上不可能出现。这不是实现问题，是算子的结构决定的。用最小时间序列把这个上限和实测对到了 1e−15。

翻译成人话。只要知道两件事，B 跟它最合适的那只股票有多像、C 跟那只股票有多像，再知道这个相似度档位下大多数配对彼此有多像，就能把 G 押到九成准。真正属于「这一对股票自己」的信息只剩那 9.4%。而这 9.4% 的内容也只有一句话，就是这对股票彼此之间比同档位的其他配对更不像还是更像，残差与「同档位平均 r 减去实际 r」的 Spearman 是 0.98。

这意味着什么
按你原来的设想，G 应该是「B、C 这一对」的性质。实测下来它九成以上是「B 和 C 各自有多合群」的性质。 拿 G 当配对互补分数去建 N×N 矩阵，矩阵里绝大部分是两只股票各自的画像，配对的成分很薄。 真正带配对含义的是残差那一层，而它的跨日稳定性只有 0.30。

三、第二个指标的反直觉否定结果

取最大近邻的覆盖核实现好了，也独立核对过（逐量比对 9 位有效数字一致）。递推从加法换成取最大。

覆盖场：找离得最近的那一笔，而不是把所有笔加起来 nmax[k] = max( nmax[k−1] · d,  u[k−1] ) nearY[k] = max( nmax[k],  nmax反向[k] ) cov(A,B) = Σk uA[k] · nearB[k]　　d = e−0.01/τ
600 个候选配对（rho 前 300 + 随机对照 300），τ=1 秒
统计量最小中位最大为正的个数
Gcov（按 ρ 的归一化方式），未过滤口径−0.9383−0.1057−0.01030 / 600
Gcov 同上，只用股票重跑−0.9383−0.0948−0.01030 / 600
为什么全为负
并集的覆盖自能量 Σk max(nearB, nearC)² 因为取最大而被抬高。例：000001 与 000004 这一对的 cov(U,U) = 1.02 × 107，是 cov(B,B) = 1.53 × 106 的 6.7 倍。分母涨得比分子快，ρ 必然被压低。

剔除基金债券后重跑，结论不变。cov(U,U) 相对单只被抬高的倍数，中位从 12.7 变成 13.2，量级没动； Gcov 仍然 600 对全部为负，中位从 −0.106 抬到 −0.095。也就是说这个否定结果不是非个股造成的，它是算子本身的性质。 另一个要注意的点，取最大核不是正定核，所以「柯西-施瓦茨保证 |ρ| ≤ 1」对求和核成立、对这个核不成立，它严格来说不能当相关系数用。

要让第二个指标能用，得把分母换成覆盖率而不是相似度。但那样增益恒为非负，必须再配零基线才行。

七、我建议的四个优化

  1. 把 X0 换成「补缺口最大」的那只。零成本，跨日 Spearman 从 0.502 升到 0.685，X0 的集中度从 50.6% 降到 20.7%。建议作为默认。
  2. 把活跃度分层空模型换掉。我原本以为它是检验，其实不是。空模型抽的配对本就和真实配对来自同一个分布，逐层均值方差都对得上（差出 3 个标准误的层数 0）， 所以 Z 只是把数据标准化了一遍，P(Z>2)=0.091% 是分布形状，不是证据。有检验力的对照是条件冗余基线，也就是把 G 对 (p, q) 回归掉之后的残差。
  3. 基金和债券必须在计算之前筛掉，而且这是代码 bug 不是优化建议。 完整证据见下一节。
  4. 往 k 只篮子的方向走比停在 2 只更有希望。贪心篮子没有塌成单枢纽，8 只篮子的相似度均值 0.456，退化比例只有 1.6%。
