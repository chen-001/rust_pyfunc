二、abm_step_two 在哪、有多重
python/rust_pyfunc/abm_analysis.py（454 行，**纯 Python**，0.76.9 和当前版本里内容基本一致）。
它依次做：
  1. adjust_afternoon(read_trade(code,date)) 取 7 个数组（时间/价/量/额/flag/买卖单号）；
  2. func(market, spec) → rp.simulate_buy_ratio_agents_py(...)  ← 这一层 Rust 里有
     （src/agent_simulator/simulator.rs 的纯 Rust 版 simulate_buy_ratio_agents）；
  3. 对 4 个 agent 各算一次 _compute_target_two_part：
       · rp.compute_agent_trading_features_multi(...) → EV_ / GRID_ / PARAM_ 三块矩阵
         （src/agent_trading_features/py_bindings.rs，Rust 里有，但要找纯 inner，不能走 #[pyfunction]）

         period_compare/complexity 开，max_min/corr/lyapunov/threshold_counts 关) → V2S_ 名字

     （GLOB_ 那批），drop 掉两列；
  5. _df_tolist 把若干 DataFrame 摊平成 res/names。
