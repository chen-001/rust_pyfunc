3. 卡点（这是没开工的原因）
   a) rp.time_irreversibility_static_detailed / _transfer_detailed 现在是 #[pyfunction] + PyResult<PyObject>，
      worker 链路不能调（链接不上 libpython）。src/ 里**没有**纯 Rust inner 版本，必须先加
      `static_detailed_inner` / `transfer_detailed_inner`（返回 i_ord / permutation_entropy /
      normalized_permutation_entropy / kl_divergence / local_irreversibility_signed / relative_bias /
      flow_direction / i_trans / entropy_rate / transition_entropy）。算法在 src/time_irreversibility.rs
      85~286 与 415~576 行，是机械改写；也可以照 DTW 那条先例在自己文件里复制一份纯 Rust 实现，不动生产代码。
   b) 特征段要走 crate::features_f64::get_features_factors_rust_full_ex，但 FeatureOpts 必须是
      with_max_min=true、with_threshold_counts=true、**with_curvature=false**、with_lyapunov_exponent=false，
      append_for_corr=Some((raw 矩阵, raw 列名))。with_curvature 默认 true 是新库特有的 curvature/quad_coef，
      Python 老函数没有，开着会多两列、整体错位。可以先拿 rp.verify_get_features_factors_rust_ex 对一遍。
   c) pandas 语义要照抄的地方：groupby().sum() 对 float64 用 Kahan 补偿求和；price=额/量；
      np.percentile 线性插值；cut 段 `safe_mean = arr[mask].mean()`（numpy mean，选中里有 NaN 就给 NaN，
      mask 为空给 0）、`safe_sum(B,mask)/(np.nansum(B)+1e-8)`、threshold 用 `A[~isnan(A)]` 的分位点、
      条件 `A > threshold`；df_all 的 sort_index 在索引有重复时并列顺序不定，先确认 order id 是否唯一。
   d) 每个组 `len(group_df) < 30` 直接返回整组 NaN。
