tlq_gate_base_resid

描述

一次算完一个因子的 base_resid 与两套 TLQ（水位口径 + 分段口径）。

入参都是行主序连续的 f64 矩阵（日期 × 股票）： factor 原始因子值 log_exret 对数超额收益（Python 侧算好） restrict 0 = 可交易 industry 申万行业码 barra k 个风格因子原始值（函数内各自 rank pct） size fill 基准（函数内 rank pct） week_first 每个交易日所属自然周的第一个交易日的下标（-1 表示该日不参与） group_from / group_to 参与 TLQ 的日期区间（Python 侧按 start/end 截）

返回 (水位口径 TLQ, 分段口径 TLQ, 十组日收益, 160 点采样曲线, 每段明细)。

函数签名

tlq_gate_base_resid(factor, log_exret, restrict, industry, barra_ranked, n_styles, size_ranked, week_first, group_from, group_to, curve_points) -> None
